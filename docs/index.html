WooCommerce Speed Checklist You Can Finish in an Afternoon

Slow product pages lose carts. This checklist is the afternoon pass we use on WordPress / WooCommerce stores before touching a redesign.

1. Measure first

  • Capture TTFB and LCP on a product page and the cart with caching cold and warm.
  • Note the heaviest JS and image requests in the network panel.

2. Caching and HTML

  • Enable full-page cache for anonymous shoppers; exclude cart, checkout, and my-account.
  • Serve a lean HTML shell; avoid page builders dumping unused CSS on every template.

3. Images and media

  • Convert hero and gallery images to WebP/AVIF with correct width/height.
  • Lazy-load below-the-fold media; keep the LCP image eager and preloaded.

4. Scripts and third parties

  • Defer non-critical scripts; remove unused tracking pixels on PDP.
  • Load chat and review widgets after interaction when possible.

5. Theme and plugins

  • Prefer a lightweight Woo-ready theme over stacked page-builder stacks.
  • Audit plugins that inject CSS/JS sitewide; keep only what checkout needs.
